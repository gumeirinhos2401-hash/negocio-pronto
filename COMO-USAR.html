Negócio Pronto: como executar

Protótipo local. Não está publicado na internet. Os dados ficam só no navegador onde a aplicação é aberta.

Executar

No PowerShell:

cd C:\Users\gustavo\negocio-pronto
npm install
npm run dev

Abra o endereço que aparecer no terminal (normalmente http://localhost:5173).

Outros comandos

  • npm test: testes automáticos.
  • npm run typecheck: verificação de tipos TypeScript.
  • npm run build e depois npm run preview: versão de produção em http://localhost:4173.

Roteiro para testar

  1. Página inicial, botão "Começar".
  2. No painel, "Ver com dados de exemplo" ou "Preencher o perfil do negócio".
  3. Publicações: gerar, editar, copiar e guardar. À sexta tentativa de guardar no mesmo mês aparece o limite do plano gratuito.
  4. Calendário: "Sugerir publicações para este mês" e mudar o estado de uma publicação.
  5. Respostas: editar e copiar uma resposta.
  6. Orçamentos: preencher, guardar e descarregar o PDF.
  7. Planos: "Experimentar o Pro" abre o checkout de simulação. Nenhum pagamento existe.
  8. Definições: "Apagar todos os dados" limpa tudo.

O que este protótipo não faz

  • Não publica em Instagram, Facebook, Google nem WhatsApp.
  • Não cobra nem processa pagamentos.
  • Não tem contas, login nem servidor.
  • Os textos são gerados por modelos de frase fixos, sem inteligência artificial.
