Negócio Pronto: como executar

Código público em github.com/gumeirinhos2401-hash/negocio-pronto. Ainda não há deploy: a aplicação só corre no teu computador.

Executar (dois terminais)

Terminal 1, a API:

cd C:\Users\gustavo\negocio-pronto
npm install
npm run server

Terminal 2, a aplicação:

cd C:\Users\gustavo\negocio-pronto
npm run dev

Abra http://localhost:5173 e crie uma conta. A base de dados fica em server\data; não é preciso instalar Postgres.

Em desenvolvimento os emails não são enviados: a ligação de confirmação e a de recuperar a palavra-passe aparecem no terminal 1.

Testes

  • npm test: testes do ecrã contra a API real.
  • npm run test:server: testes da API.
  • npm run e2e: Playwright no navegador (computador e telemóvel), com verificação de acessibilidade.
  • No GitHub, o CI corre tudo a cada push, também com Postgres 17 e scan de segredos.

Roteiro para testar à mão

  1. Criar conta. Ver o painel vazio e "Ver com dados de exemplo".
  2. Definições: preencher o perfil e guardar.
  3. Publicações: gerar, editar, copiar e guardar. Ao fim de 5 no mês aparece o limite.
  4. Calendário: sugerir o mês e mudar um estado.
  5. Orçamentos: guardar e descarregar o PDF.
  6. Planos: teste Pro simulado (só uma vez por conta).
  7. Definições: terminar sessão, recuperar palavra-passe, apagar conta.

O que não faz

  • Não publica em Instagram, Facebook, Google nem WhatsApp.
  • Não cobra pagamentos.
  • Não envia emails reais sem configurar RESEND_API_KEY e MAIL_FROM.
  • Textos gerados por modelos de frase fixos, sem IA.
